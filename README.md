# DigiMark - Digital Marketing Agency Website

A modern, responsive digital marketing agency website built with HTML, CSS, and JavaScript. This website showcases professional digital marketing services with a beautiful, user-friendly interface.

## 🌟 Features

### Design & User Experience
- **Modern Design**: Clean, professional layout with gradient backgrounds and smooth animations
- **Fully Responsive**: Optimized for all devices (desktop, tablet, mobile)
- **Smooth Animations**: CSS animations and JavaScript-powered interactions
- **Professional Color Scheme**: Blue-based color palette with proper contrast ratios
- **Typography**: Inter font family for excellent readability

### Sections
1. **Hero Section**: Eye-catching landing area with call-to-action buttons
2. **Services**: Six core digital marketing services with icons and descriptions
3. **About**: Company information with animated statistics
4. **Portfolio**: Showcase of successful projects with hover effects
5. **Testimonials**: Client feedback and reviews
6. **Contact**: Contact form and company information
7. **Footer**: Social links, navigation, and newsletter signup

### Interactive Features
- **Mobile Navigation**: Hamburger menu for mobile devices
- **Smooth Scrolling**: Navigation links smoothly scroll to sections
- **Form Validation**: Contact and newsletter forms with validation
- **Notification System**: Success/error messages for user feedback
- **Hover Effects**: Interactive elements with hover animations
- **Counter Animations**: Animated statistics in the about section
- **Parallax Effects**: Subtle parallax scrolling on hero section

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- No additional dependencies required

### Installation
1. Download or clone the project files
2. Open `index.html` in your web browser
3. The website will load with all features working

### File Structure
```
├── index.html          # Main HTML file
├── styles.css          # CSS styles and animations
├── script.js           # JavaScript functionality
└── README.md          # Project documentation
```

## 🎨 Customization

### Colors
The website uses a blue-based color scheme:
- Primary Blue: `#2563eb`
- Secondary Blue: `#3b82f6`
- Dark Gray: `#1f2937`
- Light Gray: `#6b7280`
- Background: `#f8fafc`

### Content Updates
- **Company Information**: Update contact details, address, and phone numbers
- **Services**: Modify service descriptions and icons
- **Portfolio**: Replace with actual project examples
- **Testimonials**: Add real client testimonials
- **Statistics**: Update the numbers in the about section

### Adding New Sections
1. Add HTML structure in `index.html`
2. Add corresponding CSS styles in `styles.css`
3. Add any JavaScript functionality in `script.js`

## 📱 Responsive Design

The website is fully responsive with breakpoints at:
- **Desktop**: 1200px and above
- **Tablet**: 768px to 1199px
- **Mobile**: Below 768px
